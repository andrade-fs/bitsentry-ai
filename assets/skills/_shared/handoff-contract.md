# Handoff Contract

Cross-flow handoffs are explicit and structured.

Supported transitions:
- `sdd -> sdr` when technical research is needed
- `sdd -> notes` when documentation must be produced
- `sdr -> sdd` when research becomes implementation work
- `sdr -> notes` when material is publication-ready

Each handoff must include:
- source artifact keys
- destination flow + stage
- reason
- minimum payload summary
