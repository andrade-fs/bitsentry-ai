# Result Envelope

Every skill returns:

- **Status**: `success | partial | blocked`
- **Executive Summary**: 1-3 short sentences
- **Detailed Report**: phase output
- **Artifacts**:
  - key/path
  - description
- **Persistence Actions**:
  - target: `engram | opencode | local`
  - key/path
  - content summary
- **Next Recommended**: next phase or none
- **Handoffs**:
  - to
  - reason
  - payload summary
- **Risks / Gaps**
